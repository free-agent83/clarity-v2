## Usage rules

- **Safe backgrounds:** white (`#ffffff`), off-white (`#fafaf9`), soft black (`#0c0a09`), or dark photography.
- **Minimum clear space:** 16px on all sides — or 1/4 of the logo height, whichever is larger.
- **Minimum size:** 40px width for the wordmark; 24px width for the icon. Below these the marks become illegible.
- **Never** stretch, rotate, recolour, or add effects (shadows, gradients, outlines).

In code, the [`brand`](../components/atoms/brand) component renders these assets directly so consumers don't import SVGs by hand.
