Writing for UI is its own discipline — sentence-case, action verbs, no trailing punctuation in buttons, errors that say what to do next. Clarity V2 will publish concrete patterns and a small lint surface so AI agents producing copy hit the same bar as humans. Until then, the rule is: read it aloud; if it sounds like marketing, rewrite.
