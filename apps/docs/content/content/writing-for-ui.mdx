<Gap>UI microcopy patterns are not yet written. The discipline is described below; concrete rules and lint surface are coming.</Gap>

Writing for UI is its own discipline — sentence-case, action verbs, no trailing punctuation in buttons, errors that say what to do next. Clarity by Nivoda will publish concrete patterns and a small lint surface so AI agents producing copy hit the same bar as humans. Until then, the rule is: read it aloud; if it sounds like marketing, rewrite.
