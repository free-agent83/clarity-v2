Terminology is a product contract. Use the same words everywhere so users, support, and agents all interpret the interface the same way.

## Canonical terms

- **Violet** (not purple)
- **Stone** (not grey/gray in token names)
- **Memo** (not consignment, unless legally required in specific context)
- **Supplier** (not vendor)
- **Product listing page (PLP)** for grid/list catalogue surfaces

## Naming rules

- Prefer terms already used in the live platform.
- Use one canonical term per concept; avoid synonyms in product UI.
- Expand acronyms on first mention in docs pages where clarity matters.
- Keep labels noun-first and avoid internal jargon in user-facing text.

## Migration guidance

If legacy wording exists in old screens, keep user-facing labels stable in that flow until the full screen is updated. Do not mix old/new terminology within the same surface.

## Review checklist

- Does this term already exist in another canonical screen?
- Is this wording understood by both internal and external marketplace users?
- Have alternate synonyms been removed from nearby labels and help text?
