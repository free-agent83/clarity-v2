<Gap>Loading-state timing and shimmer behaviour are not yet specified. The skeleton-over-spinner preference is described below; concrete timings are coming.</Gap>

Loading states prefer skeletons over spinners — the skeleton promises what's about to render, so layout doesn't shift and the user's eye stays anchored. Spinners are reserved for action feedback (button submitting, inline operation), not page loads. Detailed timing thresholds and shimmer behaviour will follow.
