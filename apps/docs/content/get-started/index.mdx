Clarity V2 is Nivoda's design system: W3C DTCG tokens, shadcn/ui components, and Tailwind v4, in an Nx monorepo. The promise is simple — whoever builds UI (engineer, designer, or PM with an AI agent) produces design-correct output by default. The components ARE the design.

## What's in here

- **Foundations** — tokens, colour, typography, spacing, elevation, motion. The primitives every component is built from.
- **Components** — 60+ shadcn-based primitives, regrouped functionally (Actions, Forms, Display…) rather than atomically.
- **Patterns** — multi-component compositions like the product listing page kit.
- **Content** — voice, terminology, writing for UI.
- **Brand** — logo, expression, illustration.
- **Resources** — the roadmap, vision, architecture, ADRs, and changelog.

## Who this is for

- **Engineers** consuming `@nivoda/components` and `@nivoda/tokens` directly.
- **Designers and PMs** building flows in [Minivoda](../guides/architecture/architecture) with AI coding agents — same library, same guarantee.
- **Anyone** evaluating where the system is and where it's going. Start with [Vision](./resources/vision) and [Roadmap](./resources/roadmap).
