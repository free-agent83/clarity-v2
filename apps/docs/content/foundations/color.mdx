Colour in Clarity V2 is authored in OKLCH for perceptual uniformity, with hex fallbacks for React Native. The brand colour is **violet** (not purple) and the neutral is **stone** (warm, not cool grey). Black is soft (`#0c0a09`), not true black. Detailed guidance on ramps, semantic roles, and dark-first behaviour is coming — in the meantime, see `packages/tokens/tokens/color/` in the repo.
