Clarity V2 uses a serif display family for headings and a humanist sans for UI and body. The pairing carries the brand's luxury-marketplace direction without losing the readability fintech surfaces demand.

The full type scale is implemented in the [Typography component](../components/atoms/typography), which is the canonical way to render text. Reach for it instead of raw HTML headings — it owns the scale, weights, line-heights, and tracking so the system stays consistent.

## Quick reference

- **Display & headings:** serif, used sparingly for marketing surfaces and hero content.
- **UI & body:** sans-serif, every functional surface.
- **Numeric & code:** monospace, with tabular figures where alignment matters.

Tokens live under `typography.*` in `@nivoda/tokens`. Written guidance on usage pairs and editorial nuances follows in a later pass.
