Clarity V2's tokens are authored in W3C DTCG JSON, transformed by a bespoke ~200-line build script (see [ADR-001](../resources/adrs)), and emitted as Tailwind v4 CSS, React Native objects, and a shadcn-flat surface. Written guidance on the token taxonomy, themes, and consumption patterns is coming as the system stabilises — in the meantime, see `packages/tokens/` in the repo.
